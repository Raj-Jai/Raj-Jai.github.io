How it works

site acronym + seed → character-code transformation → case flip at two positions → @0616 suffix

This page reproduces the original Pass Encrypt algorithm exactly so old passwords keep working. It is a deterministic transformation, not cryptographic encryption, hashing, or a password manager.

Security note

  • Processing happens entirely in your browser. Nothing is stored or transmitted.
  • Do not use this for banking, primary email, or recovery credentials.
